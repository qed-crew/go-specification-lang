# Verified Go insertion sort

`insertion_sort.go` is ordinary compilable Go with GPMA contracts and loop
invariants. `semantics.go` exercises parameter evaluation order, short-circuit
evaluation, simultaneous assignment, `continue`, `break`, early returns and
shadowing.

From the repository root:

```sh
./whyml-demo/verify.sh
```

This checks the Go implementation, translates both examples, proves their
generated WhyML, and runs positive and negative integration tests for both
32-bit and 64-bit Go integers. It writes reviewable `.mlw` files and proof
logs to `generated/`. The checked-in files are generated by the translator,
with no manual proof edits.

To inspect the sorting proof interactively:

```sh
why3 ide whyml-demo/generated/insertion_sort.mlw
```

See `framework/plugin/whyml/README.md` for installation, API/CLI usage,
supported syntax, semantic differences and the prototype's trust boundary.
`PROOF_REPORT.md` records the actual validation results.
